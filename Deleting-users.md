To block, anonymize, or delete users:
1. Navigate to the **Users** page in the main navigation menu (`/admin/users`).
2. Select the checkbox(es) next to the user(s) you wish to manage.
3. In the upper right dropdown menu **Aktionen** (*Current result*), select **Block or delete selected users...** (*Markierte sperren oder löschen...*).
4. A dialog will appear letting you choose which of the following four actions to perform on the selected accounts:

### Block user
Users will be marked as blocked - they can't log in anymore, but all data will remain in the system. Blocking can be removed later. Blocked users will not appear on the page for assigning new users, but they will appear on the list of assigned users, styled as crossed out.

### Delete user
Personal data will be removed permanently, but the user will still appear in sessions as anonymous. So the payout and participation information will be kept, but you will not be able to identify the user.

### Delete and blacklist user
Personal data will be removed permanently and the email will be blacklisted, but the user will still appear in sessions as anonymous. So the payout and participation information will be kept, but you will not be able to identify the user. You can find the blacklisted emails and other attributes in the settings area, where you can also remove entries from the blacklist.

### Erase all user related information:
All user data will be deleted permanently. Warning - this will also delete all session participation entries and any history entries of emails, so it will remove session history entries and payout information and wipe any information of the user entirely.
