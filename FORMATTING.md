The following are guidelines for how the wiki should be formatted.

---

## Contents

All pages should be added At a suitable position in the sidebar to the right of the page.

## Pages

The page name is the header of the page. Don't add a header repeating the page name. 

Under the page name, add a short description of what the page explains, with an horizontal line beneath.

If there are multiple subsections on a page, number them and add a horizontal line in-between each two. Also add a content page at the top.

## Text

Technical information are to be highlighted as code, like so: `Text`

When pointing to a page in hroot, make it bold and add an arrow between each to levels. For example **Site Settings -> Participation Pools**
