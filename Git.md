Obviously, being a github project, another requirement for hroot is a working local installation of Git. You can use any client, although most of the examples will be using Git shell commands.

See the github guide to Git (https://help.github.com/articles/set-up-git) to learn about git or see the git homepage (http://git-scm.com/).

If you have successfully installed Git and you can successfully run

    git --version

on a shell, you are ready to proceed to the installation chapter of hroot.
