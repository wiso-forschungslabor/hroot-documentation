### Text comments on users

If you want to have additional information about users, you can use the text field _comments_ (part of the edit form for users). Once you have entered one or more characters, this information will be available on the user list as a popup to quickly see the comments on the users.


### Finding duplicate users

As an admin, you can navigate to **Site Settings -> Duplicate Users** (*Doppelte Benutzer* under *Participants & Master Data*) or use the **Duplicate accounts** filter on the **Users** page. See [Finding duplicate users](Finding-duplicate-users.md) for detailed matching rules and merge workflows.

## Icons and crossed users

In the user table, various status and indicator icons may appear next to a user's record (e.g. comment bubble for notes, warning icons for duplicate suspicions, exclamation marks for pending verifications, or status indicators).

**Hovering with the mouse over any icon displays a tooltip explaining its exact meaning.**

Crossed-out / dimmed user rows represent accounts that have been blocked, deactivated, or anonymized, but are retained in the database for historical and compliance documentation.
