After installing hroot using our installation guide, you start off with a very first user, see [Manual Deployment](Manual-Deployment.md) or [Docker Deployment](Docker-Deployment.md) on how to create the initial admin user.

To prepare for your first experiments, you might want to setup some additional data: Head over to [Settings](Settings.md) where you can add your experiment locations. Also, now is a good time to author the default texts for emails sent by the system - these default texts will be copied to new experiments and can be changed by the experimenters.

To learn more about the system, read [Roles: Users, Admins, Experimenters](Roles:-Users,-Admins,-Experimenters.md) and [Experiments, Sessions, session types](Experiments,-Sessions,-session-types.md).

If you want to create your first experiment, read [Managing Experiments](Managing-Experiments.md).

Some text parts of the site can be configured, like the text on the start page or the text users see after login. You should customize these texts (settings/texts).
