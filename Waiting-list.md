
The waiting list is designed to gather users who could participate in a session but were not able to get a seat. 
It can be enabled per experiment by setting a maximum number of waiting list seats in the experiment settings (0 disables it)

Once a session is fully booked, users can now register with the waiting list of this session. As soon as a seat opens up (due to another user cancelling), all users on the waiting list will get an email notifying them about the free seat. You can customize the content of this email on the page "Email texts".

Notifications are sent out, when the number of open seats changes from 0 to a positive value - so if multiple users cancel in a short period of time, only one notification will get sent to the people on the waiting list.

If you remove a user from a session manually as an admin, no notifications will be sent out. However, you can trigger the notification manually in the session list view. You can also see the number of notifications having been sent, in case you worry about spamming your user base.

Another setting in the experiment settings is the value "cancellation hours" - this specifies, how many hours before a session the user is allowed to cancel his/her participation.
